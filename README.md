# Chat App

A realtime chat built with React, TypeScript and Firebase (Authentication + Cloud Firestore).
Users sign in with Google and talk in a single shared room. Messages show the sender's name and time.

## Stack

- React 19 + TypeScript (Create React App)
- Firebase Authentication (Google provider)
- Cloud Firestore (`messages` collection)
- `react-firebase-hooks` for auth state and realtime data
